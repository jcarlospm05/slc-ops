# WorkFlow Android

Aplicación Flutter/Dart offline de gestión operacional. Nombre público: **WorkFlow**.

Rama: `workflow-android`. El paquete fuente se conserva en Drive y `workflow-src.zip` se utiliza en GitHub Actions para compilar.

La nueva aplicación usa `com.workflow.operaciones` para instalarse sin reemplazar la aplicación anterior, y ofrece importación de respaldo JSON. SQLite sigue local en el teléfono.
